# U-Mamba-DLKA with Artificial Rabbits Optimization for Liver CT Segmentation

## 1. Dataset

The proposed framework is evaluated using the Liver Tumor Segmentation (LiTS) dataset, which contains abdominal computed tomography (CT) volumes and corresponding segmentation annotations. The dataset is used to investigate automated liver segmentation under variations in anatomical morphology, organ boundaries, and surrounding abdominal structures.

The annotated dataset comprises **131 CT volumes**, partitioned at the volume level as follows:

| Dataset subset | Number of CT volumes |
|---|---:|
| Training | 92 |
| Validation | 13 |
| Testing | 26 |
| **Total** | **131** |

The preprocessing pipeline includes the following operations:

- Loading CT volumes and corresponding segmentation masks.
- Applying Hounsfield Unit (HU) windowing within the range of −150 to 250.
- Applying min–max normalization.
- Converting three-dimensional CT volumes into two-dimensional axial slices.
- Resizing images and masks to 256 × 256 pixels.
- Applying data augmentation to the training data.


## 2. Proposed Methodology

The proposed U-Mamba-DLKA framework integrates a U-Mamba encoder, a Deformable Large Kernel Attention (DLKA) module, and a U-Net decoder. Artificial Rabbits Optimization (ARO) is incorporated to identify an appropriate hyperparameter configuration for model training.

### 2.1. U-Mamba Encoder

The U-Mamba encoder extracts hierarchical anatomical representations from preprocessed CT slices. Convolutional operations capture local image characteristics, while selective state-space modelling supports the representation of long-range contextual dependencies. This combination provides feature representations for subsequent spatial refinement and segmentation reconstruction.

### 2.2. Deformable Large Kernel Attention

The DLKA module refines the contextual feature representations generated by the encoder. Deformable depth-wise and dilated convolutional operations are employed to adapt spatial sampling and capture contextual information across larger receptive fields. This feature-refinement stage is designed to support the delineation of irregular liver boundaries and complex anatomical structures.

### 2.3. U-Net Decoder

The U-Net decoder progressively reconstructs the segmentation output through upsampling and skip connections between corresponding encoder and decoder stages. The final output layer generates pixel-wise liver segmentation probabilities using sigmoid activation. A predefined threshold is then applied to obtain the binary segmentation mask.

### 2.4. Artificial Rabbits Optimization

ARO is employed to optimize four training hyperparameters: learning rate, weight decay, batch size, and dropout rate. Candidate configurations are evaluated using the training and validation datasets, and the optimization process identifies a configuration according to the specified fitness evaluation and stopping criteria.

The selected hyperparameters are subsequently used to train the complete U-Mamba-DLKA framework. The optimizer, loss function, learning-rate schedule, activation functions, and final training duration remain fixed according to the experimental configuration.

### 2.5. Overall Workflow

The complete workflow consists of dataset preprocessing, ARO-based hyperparameter optimization, final model training, segmentation inference, and quantitative evaluation.

## 4. Training Configuration

The final training configuration combines ARO-optimized hyperparameters with fixed model-training settings.

| Hyperparameter | Final configuration | Setting type |
|---|---|---|
| Learning rate | 0.0001 | ARO-optimized |
| Weight decay | 0.0001 | ARO-optimized |
| Batch size | 16 | ARO-optimized |
| Dropout rate | 0.20 | ARO-optimized |
| Optimizer | Adam | Fixed |
| Loss function | Dice Loss + Binary Cross-Entropy Loss | Fixed |
| Learning-rate schedule | Cosine annealing | Fixed |
| Training duration | 100 epochs | Fixed |
| Activation functions | ReLU, SiLU, GELU, and sigmoid | Fixed |

The ARO-selected configuration is used for final training of the complete segmentation framework over 100 epochs. Cosine annealing is applied to adjust the learning rate during training, while the specified activation functions are used within their respective architectural components.
